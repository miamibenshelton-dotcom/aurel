# Aurel

Boutique e-commerce premium de parfums créée pour offrir une expérience luxe, moderne et crédible.

## Stack
- Next.js 14
- TypeScript
- CSS module via globals.css
- Local cart state (prêt pour Stripe et Supabase)

## Installation

```bash
npm install
npm run dev
```

Puis ouvrir : http://localhost:3000

## Déploiement
- Frontend : Vercel
- Variables d’environnement : `.env.local`
- Paiement : ajouter Stripe ensuite

## Fonctionnalités incluses
- Accueil premium
- Catalogue produits
- Filtres
- Page produit
- Panier local
- Checkout simulé
- Admin
- FAQ, À propos, Contact
- Branding Aurel
